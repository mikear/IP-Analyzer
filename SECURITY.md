# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.2.x   | Yes       |
| < 2.2   | No        |

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/mikear/IP-Analyzer/security/advisories/new).

Please include:

- Steps to reproduce
- Affected version / OS
- Logs with secrets removed (never paste `IPINFO_TOKEN` or case data)

## Response time

Expect an acknowledgement within 72 hours and a fix or mitigation plan within 14 days for validated reports.

## Scope

IP Analyzer is a defensive local tool for authorized forensic work. Vulnerabilities in ipinfo.io, PySide6, or the OS itself are out of scope unless they affect the app's handling of untrusted input files or tokens.
